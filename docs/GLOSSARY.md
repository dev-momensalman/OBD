# 📖 GLOSSARY.md — Automotive & Technical Terminology

| Acronym / Term | Full Term | Definition |
|---|---|---|
| **OBD-II** | On-Board Diagnostics II | Standardized automotive electronic protocol mandatory on all light vehicles since 1996. |
| **DTC** | Diagnostic Trouble Code | Standardized 5-character alphanumeric fault code (e.g. `P0301`) generated by a vehicle ECU. |
| **CAN Bus** | Controller Area Network | High-speed vehicle internal serial network allowing ECUs to broadcast messages. |
| **ECU** | Electronic Control Unit | Microcontroller embedded in vehicle governing engine, transmission, ABS, or body electronics. |
| **PID** | Parameter Identification | 2-byte hexadecimal identifier in OBD-II queries requesting specific telemetry (e.g. `010C` = RPM). |
| **Freeze-Frame** | Mode 02 Data Snapshot | Snapshot of all critical engine sensors frozen by the ECU at the exact moment a DTC was stored. |
| **MIL** | Malfunction Indicator Lamp | The dashboard 'Check Engine Light' indicating active emission or engine faults. |
| **ELM327** | ELM327 Command Interpreter | Microcontroller specification translating RS-232/UART commands to automotive bus protocols. |
| **STFT / LTFT** | Short / Long Term Fuel Trim | Real-time percentage adjustments made by ECU to fuel injection pulse width to maintain stoichiometric ratio (14.7:1). |
| **RAG** | Retrieval-Augmented Generation | AI pattern retrieving domain facts from vector databases before prompting an LLM to eliminate hallucinations. |
| **DLC** | Data Link Connector | Standard 16-pin trapezoidal connector located under vehicle dashboard. |
